# TOPIK 분석 시스템 — Windows 설치

[최신 설치 파일 다운로드](https://github.com/duduyadu/topik-analysis-releases/releases/latest)

Windows x64용 TOPIK 시험 분석 및 한국어·베트남어 보고서 프로그램입니다. 이 저장소에는 검증된 설치 파일과 업데이트 정보만 배포합니다.

## 설치

최신 릴리스의 `Setup` EXE를 다운로드해 설치하세요. 기존 버전에 업데이트 알림 기능이 없다면 한 번 직접 설치해야 합니다.

설치 후 새 버전이 배포되면 프로그램에서 안내합니다. 다운로드와 설치를 선택할 수 있으며, 도움말 → 업데이트 확인에서도 확인할 수 있습니다. 작업 내용을 저장하고 분석·PDF 생성을 마친 후 설치하세요. 기존 학생 자료와 보고서는 유지됩니다.

## AI 연결

프로그램의 AI 연결 설정에서 ChatGPT 또는 Google 계정으로 Gemini를 연결하고, 사용할 모델을 선택한 뒤 연결 확인을 실행하세요. Gemini는 공식 CLI를 통해 연결하며 계정별 사용 한도를 따릅니다. 회사·학교 Google 계정은 별도 설정이 필요할 수 있습니다.

학생 이름·ID·소속을 제외한 성적 근거만 선택한 AI 제공업체에 전송합니다. AI 초안은 사용자가 검토하고 저장합니다.

소스코드와 운영 자료는 이 저장소에 포함하지 않습니다.
